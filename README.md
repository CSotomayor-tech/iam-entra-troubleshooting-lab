## Overview
This project demonstrates hands-on Identity and Access Management administration using Microsoft Entra ID in a lab environment.All tasks were performed in a cloud-based Microsoft Entra ID tenant simulating a real-world enterprise identity environment.

## Objectives
The goal of this project was to simulate core IAM tasks commonly performed in enterprise environments, including user provisioning, group-based access control, role assignment, identity lifecycle management, and log review.

## Tasks Completed
- Created and managed user accounts in Microsoft Entra ID
- Built security groups for role-based access organization
- Assigned users to groups based on job function
- Assigned the User Administrator role using built-in RBAC
- Simulated joiner, mover, and leaver identity lifecycle events
- Reviewed sign-in logs for visibility into identity activity

## Skills Demonstrated
- Microsoft Entra ID administration
- User provisioning and deprovisioning
- Group-based access control
- Role-Based Access Control (RBAC)
- Least privilege principles
- Identity lifecycle management
- Log analysis

## Business Value
These activities reflect real-world IAM responsibilities that support secure access, operational consistency, and identity governance across enterprise environments.
